# Attribution

The web app in this repository started from the MIT-licensed
[shadcn-saas-landing](https://github.com/techwithanirudh/shadcn-saas-landing) template
by Anirudh (techwithanirudh), commit `51027da3b5278cc632be59e893f67136ea3d919a`.
Its copyright notice is preserved in [`LICENSE`](./LICENSE) alongside the notice for this project.

What is derived from the template: the Next.js project structure, the shadcn/ui component set,
the Fumadocs-based docs and blog layout, and the marketing page scaffolding. Everything else
(the `/app` dashboard, wallet integration, contracts, deployment tooling, docs content, blog posts)
was written for Carbonized.
