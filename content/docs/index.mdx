---
title: Introduction
description: Carbonized is a carbon-credit marketplace on EVM chains, deployed to Robinhood Chain Testnet and being prepared for Robinhood Chain mainnet.
---

Carbonized lets companies and traders trade, auction and retire tokenized carbon credits onchain. Each credit is an ERC-721 NFT created by an authorized issuer and carrying project metadata; credits can be wrapped 1:1 by tonnes of CO2 into ERC-20 tokens that trade on a marketplace combining an order book, timed auctions and an AMM pool (the AMM is not wired into the web app yet).

<Callout type="warn" title="Unaudited software">
  The contracts have not been audited by an independent firm. The public deployment runs on **Robinhood Chain Testnet** (chain id `46630`) with a mock payment token and a mock Chainlink Functions router. Robinhood Chain mainnet (chain id `4663`, real 6-decimal payment token) is being prepared: see [Robinhood Chain Mainnet](/docs/deployment/robinhood-mainnet). The app shows a "Testnet / unaudited" banner on every build that is not configured for mainnet. A credit in Carbonized is a token issued by an authorized issuer; a retirement certificate proves a token was burned, not that the underlying project is real.
</Callout>

## What is in the box

| Layer | What it is |
| --- | --- |
| Smart contracts | `CarbonCreditNFT`, `CarbonCreditToken`, `CarbonMarketplace`, `CarbonRegistry`, `CarbonPriceOracle`, `EmissionVerifier`, `RegistrySync` (Solidity 0.8.20, OpenZeppelin 4.9, Chainlink Functions client) |
| Web app | Standalone app at `/app` with its own dashboard layout and an EN / 中文 language toggle: dashboard, marketplace, auctions, portfolio, sell credits, certificates, credit requests, company and trader onboarding. The marketing site lives at `/`. |
| Wallet | Reown AppKit (WalletConnect) plus injected wallets such as MetaMask |
| Backend (optional) | An HTTP API at `NEXT_PUBLIC_BACKEND_URL` for an off-chain depository. Leave it empty unless you run one: it receives company registration details. |
